# 投资银行专家团（公共版）

A 股 IPO 多角色专家团队框架：主理人编排 + 财务/法律/行业三专家 + 文档采集/管理 + 写作专家，共 7 角色。**平台无关内核**——同一套角色卡与协作 SOP，可在 WorkBuddy、Claude Code 及任何对话平台使用。

作者：默光 ｜ 版本：v1.0.0 ｜ 分类：金融投资

## 它能做什么

- **IPO 项目分析**：三专家并行（财务/法律/行业）→ 写作专家综合成文 → 主理人门禁交付
- **文档采集归档**：公开披露平台检索下载招股书/问询回复 → 校验重命名 → 归档台账勾稽
- **申报级文书**：招股书章节/问询回复/备忘录（含 000-009 样式 docx 模板）
- **质量门禁**：数字五要素、绝对化清零、三方引用门、引用对照表、6 维 30 分自评（自包含，无外部依赖）
- **蒸馏学习**（可选）：从零建自己的方法论库（空库友好 SOP）

## 三种用法（选一即可）

### ① WorkBuddy
将本目录放入专家目录（`~/.workbuddy/plugins/marketplaces/my-experts/plugins/`），注册后于专家中心启用。团队 = 7 个子代理，主理人自动编排。

### ② Claude Code
```bash
cp claude-code/agents/*.md  <你的项目>/.claude/agents/    # 项目级
# 或 cp claude-code/agents/*.md  ~/.claude/agents/         # 用户级
```
主对话即主理人（按 `core/ARCHITECTURE.md` 七拍编排），六个子代理按需自动调用。详见 `claude-code/INSTALL.md`。

### ③ 任何对话平台（网页版 ChatGPT/Claude 等）
把 `core/TEAM-HANDBOOK.md` 全文作为 System Prompt / 首条消息发出。单模型分角色串演（无真并行，边界见手册声明）。

## 目录结构

```
ibd-expert-team-public/
├── core/                 # ★平台无关内核（角色卡×7 / 架构文档 / 质量门禁 / 通用工作手册）
├── agents/               # WorkBuddy 适配器（7 成员定义）
├── claude-code/          # Claude Code 适配器（subagents + 安装说明）
├── references/
│   ├── templates/        # 写作模板（000-009 样式 docx + md 骨架）
│   └── sop/              # 蒸馏 SOP（空库友好版）+ 知识库体检 SOP（通用版）
├── scripts/              # 验收单机检脚本
├── avatars/              # 成员头像
└── .codebuddy-plugin/    # WorkBuddy 注册清单
```

## 进阶（可选，非必需）

- **ibd-skills 规程集**（GitHub `Kianchales/ibd-skills`）：质量把关/投行写作/财务法律复核/方法论库管理等九个独立技能包，含方法论库配置教学。本包**无它也能完整运行**；安装后分析/写作链路自动获得方法论定向引用增强。
- **蒸馏学习体系**：按 `references/sop/distill-sop.md` 从零建库，每读一案沉淀可复用条目。

## 边界声明

- 非持牌投顾：输出为分析框架与文书支持，不构成投资建议；最终判断由持牌专业人员负责
- 敏感法律定性（明股实债/票据资质/虚开类）只列选项与后果，结论由用户裁定
- 纯对话平台为单模型分角色串演（物理上限，如实声明）
